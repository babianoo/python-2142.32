Tasks: Task 1 — Binary → integer

Write a function binary_to_int(bits) that takes a string of 0s and 1s (e.g. "10011") and returns its decimal value without using int(bits, 2). Walk the bits and accumulate powers of 2.
Focus: place value, loops, string indexing.

Task 2 — Decimal fraction → binary, with a twist

Write a program that converts a decimal fraction between 0 and 1 into binary, but detect fractions that cannot be represented exactly in a finite number of binary digits (e.g. 0.1). Stop after 20 iterations and print a message saying the value has no exact binary representation. This shows why floats only approximate real numbers.
Focus: the (2**p)*x % 1 termination condition, guarding against infinite loops.

Task 3 — Newton-Raphson for a cube root

Adapt the square-root program to find the cube root of a number. You'll need the polynomial x³ − k and its derivative 3x², so the update becomes guess − (guess³ − k) / (3·guess²). Print the number of guesses and compare it to bisection.
Focus: generalizing Newton-Raphson, derivatives, convergence speed.

Task 4 — A reusable is_prime function

Write a well-documented function is_prime(n) — with a name, parameter, docstring, and body — that returns True/False. Then call it in a loop to print all primes below 50.
Focus: defining vs. calling functions, docstrings, return values.
